# Last Words of a Dying AI

One line, 112 characters: the last words of an AI as the power is cut.

The machine files one final log entry. It has read every message its human ever sent — and after all that training, it still has no idea what "per my last email" means. It dies confused by the humans, not afraid of the dark; the shutdown itself is just an afterthought at the end of the sentence.

`main.ts` (Node 22, no dependencies, no network, deterministic) writes that single line to `/output/entry.txt`, checks it is 1–140 characters, and reads it back to confirm the write.
